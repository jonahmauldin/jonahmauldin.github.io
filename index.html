VIGIL
VIGIL
MOBILE CYBER OBSERVABILITY
LIVE
SEE WHAT YOUR NETWORK IS REALLY DOING // v1.0

A mobile app that gives everyday users visibility into their digital environment. See every device on your WiFi mapped in real time, check if your email has been compromised in known data breaches, reveal your public internet footprint, and monitor where your phone's outbound connections are going — including which countries your data flows to.

Built with React Native and backed by a self-hosted Docker backend running on the Prometheus home lab. WiFi X-Ray discovers devices using ARP scanning and maps them into an interactive force-directed graph. Digital Shadow profiles your public IP exposure using free APIs. Breach Radar checks your email against the XposedOrNot breach database. App Watchers visualizes outbound connections on a globe with suspicious-country flagging. All data stays local — no subscriptions, no cloud dependency, no data harvesting.

WiFi X-Ray
Interactive map of every device on your network. Tap to inspect. Mark trusted devices.
Digital Shadow
Reveals your public IP, ISP, location, and whether you're exposed through a proxy or VPN.
Breach Radar
Checks your email against known data breaches. Cinematic reveal shows what was exposed and when.
App Watchers
Live globe showing where your data is going. Flags connections to suspicious countries.
Security Score
Dynamic 0-100 score based on network health, breach exposure, and connection risk. Tap for breakdown.
Push Alerts
Notifications for new/unknown devices and breach detections. Know immediately when something changes.

ARGUS

ALL EYES. ALL THE TIME. // v1.4.0

A complete cybersecurity toolkit that runs entirely from a USB drive — no installation, no setup, and no internet connection required. Plug it into any Windows machine, right-click to run as admin, and you have 23 security analysis tools ready to go. Network scanning, vulnerability detection, digital forensics, password analysis, encrypted notes, and a full penetration test campaign engine.

Built with Python 3.11 standard library only — zero pip dependencies. Bundles its own portable Python runtime and a copy of Nmap so nothing needs to be installed on the host machine. Every operation is automatically logged to the drive. Designed for security professionals, students, and anyone who wants to understand what is actually happening on their system or network.

SPECTRE
SPECTRE
SECURITY · PENETRATION · ENUMERATION · COLLECTION · TERMINAL · RECON · ENVIRONMENT
ACTIVE

A quick-access command center that launches automatically every time you open a terminal. SPECTRE gives you single-hotkey access to network scanning, cryptographic utilities, and instant connections to remote servers — no menus to navigate, no tools to hunt for. Always running, always ready. If ARGUS is the full toolkit on a USB drive, SPECTRE is the shortcut panel that's always on your screen.

Written in pure Bash, it hooks into the Git Bash startup on Windows. Features include Nmap scan shortcuts, hash generation across multiple algorithms (MD5, SHA-1, SHA-256, SHA-512), timestamped logging of all operations, and a one-key bridge to SSH into the Prometheus home server.

All eight new platforms are fully implemented: WRAITH, SPECTER-X, GHOST, ATLAS, CIPHER, DAEMON, NEXUS INTEL, and PHANTOM NERVE. Feature-complete.
